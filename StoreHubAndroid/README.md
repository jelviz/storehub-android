# DINAL StoreHub V16 — Android Only

StoreHub V16 همچنان Android-only است. دیتای اصلی فروشگاه در Room روی گوشی می‌ماند و عملیات روزمره بدون Backend/VPS انجام می‌شود.

## V16 — دستیار DINAL داخل اپ
یک صفحه جدید با عنوان «دستیار DINAL» اضافه شده است.

- با همان OpenAI API Key بخش ثبت هوشمند کار می‌کند.
- کاربر می‌تواند سؤال‌های فروشگاهی بپرسد؛ مثل موجودی کم، چک‌های نزدیک سررسید، فروش‌های اخیر و پیشنهاد اقدام.
- گزینه «استفاده از اطلاعات محلی فروشگاه» دارد. وقتی روشن باشد، StoreHub فقط یک خلاصه مرتبط از دیتای محلی خود اپ را همراه سؤال برای OpenAI می‌فرستد.
- StoreHub هیچ دسترسی مستقیمی به گفتگوها یا Memory اپ ChatGPT ندارد.
- پاسخ‌ها فارسی و با مبالغ تومان طراحی شده‌اند.
- برای درخواست‌های Responses API مقدار `store=false` ارسال می‌شود.

> حالت فعلی برای استفاده شخصی/آزمایشی کلید API را با Android Keystore روی گوشی نگه می‌دارد. برای انتشار عمومی یا استفاده سازمانی، نگهداری کلید در یک سرویس واسط امن‌تر است.

## چرخش گوشی بدون ریست صفحه
MainActivity تغییر orientation و screenSize را خودش مدیریت می‌کند تا با چرخاندن گوشی Activity از نو ساخته نشود. همچنین بخش‌های مهم فرم ثبت هوشمند از state قابل‌ذخیره استفاده می‌کنند تا متن‌های واردشده بی‌دلیل نپرند.

## ML Kit دیگر ثبت هوشمند را قفل نمی‌کند
در نسخه‌های قبل اگر Subject Segmentation دانلود نمی‌شد، کل ثبت هوشمند متوقف می‌شد. در V16:

1. اپ در پس‌زمینه تلاش می‌کند مدل ML Kit را آماده کند.
2. اگر مدل آماده بود، بک‌گراند حذف و تصویر روی سفید قرار می‌گیرد.
3. اگر مدل آماده نبود یا پردازش شکست خورد، عکس همچنان به WebP تبدیل می‌شود و AI/انتشار ادامه پیدا می‌کند.
4. دکمه «تلاش مجدد حذف بک‌گراند» باقی می‌ماند تا بعداً دوباره امتحان شود.

## استاندارد مبلغ
تمام مبالغ StoreHub بر مبنای تومان هستند و ورودی‌های پولی با جداکننده سه‌رقمی نمایش داده می‌شوند؛ نمونه: `125,000,000 تومان`.

## QR و لیبل 50×30
- QR کالای WooCommerce لینک واقعی صفحه محصول است، نه قیمت.
- حالت چاپ: فقط QR، QR+قیمت، QR+نام+کد، یا لیبل کامل.
